## Step 1 of 4: Before the shoot (Andrew, about 20 minutes at the location, estimate)

| # | Do this | Why |
|---|---|---|
| 1 | Both iPhones: 4K, 30 fps, HDR Video OFF (Settings, Camera, Record Video), same frame rate on both | Shoot 1 needed an HDR conversion; mixed frame rates break sync |
| 2 | Lock exposure and focus on each phone (hold on Tom until AE/AF LOCK shows); Do Not Disturb on; check free storage (about 1 GB per 6 min per phone at 4K30, estimate) | A phone hunting for focus ruins a take; a full phone ends the shoot |
| 3 | One continuous recording per camera for the whole session, started in this order: screen, front, side. Clap once in view of both phones with screen recording running | One long take per source is what the shoot-1 sync tool handled with zero drift. The clap is a second check |
| 4 | Lav on Tom into the FRONT phone (confirm, see ask below). Side phone records scratch audio only, used for sync and never heard | One voice track. Two live mics on one person produces phase and level trouble |
| 5 | Front phone at laptop-screen height, near the lens line Tom will glance at; side phone at 90 degrees, same height, Tom's keyboard hand visible | Gives a front shot that reads as eye contact and a side shot that reads as work |
| 6 | Tom's screen: clean browser at 1920x1080, zoom 125%, notifications off, searches pre-loaded, cursor still while talking, no right-clicks | Shoot 1 fixes 2 and 3 (phase 7) |
| 7 | Take the order from Tom's script. Record each story beat and each demo beat as its own short take, restart from the top of a stumbled sentence | Cuts land in the pauses; shorts need self-contained takes |
| 8 | Releases signed BEFORE rolling; consent line spoken on tape; room tone 30 s at the start | Shoot 1 had no signed release |

## Step 3 of 4: Paper edit and build

| Step | Rule |
|---|---|
| Script first | Tom's script is the spine. Get it as a file BEFORE the shoot so each take is tagged to a script line |
| Persuasion check | Run `/storytelling` on the script at the purpose step (target emotion, the non-obvious angle). That is Tom's design call, so offer it as a read, not a rewrite |
| Paper edit | Word-level transcript from the master (front phone with lav); pick segments by first and last WORDS, as in shoot 1 |
| Builder | Copy `build_rough_cut_REFERENCE.py`, edit config only, plus ONE new idea: a `picture` can be `front`, `side` or `scr`, and a segment may carry a list of picture switches inside it (for example front for the first sentence, scr for the proof, side for the finish). Needs a small code change, built when footage exists |
| Switch rule | Every picture switch lands in a pause or on a gesture; scr is always shown while a product claim is spoken |
| Sample first | Producer builds ONE 20 to 30 s sample (hook plus one demo beat) before the full cut, then Verifier |
| Rights | `rights-gate.py` review copy, then `--public`. Music still not cleared: Suno free tier is review-only |
